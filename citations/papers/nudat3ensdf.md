## TL;DR

Primary evaluated-data interface for nuclide properties used by Statera's Track A data policy.

## Relevance

NuDat exposes datasets relevant to Statera visualizations, including half-life, decay mode, Q-values, separation energies, excited states, cross sections, and fission yields.

## Key Facts

- NuDat level, gamma, and decay sections are based on ENSDF.
- The exposed dataset categories include `Q_alpha`, half-life, decay mode, separation energies, excited states, cross sections, and fission yields.

## Limitations

The website is a data interface. Imported values still need local provenance records, units, uncertainties, and tests.
